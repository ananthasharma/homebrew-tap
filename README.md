# ananthasharma/homebrew-tap

```bash
brew tap ananthasharma/tap
brew install --cask slicky
```

## Slicky

A small robot who lives on your desktop, hops around when the mood takes him,
and opens the apps you hand him.
[github.com/ananthasharma/Slicky](https://github.com/ananthasharma/Slicky)

The cask here is a mirror; the source of truth is
[`Casks/slicky.rb`](https://github.com/ananthasharma/Slicky/blob/main/Casks/slicky.rb)
in the Slicky repo, updated by its `build.sh --release`.
